Fanuc Cobot Kinematics Playground — Research & Docs

                
            

            

                
Welcome to the Fanuc Cobot Kinematics Playground, developed and authored by Ankit Satnami. This simulator provides comprehensive 6-DOF kinematics modeling, real-time DH transformation matrices, analytical inverse kinematics solutions, and differential Jacobian analysis.

                
Author: Ankit Satnami | GitHub: @Ankitsatnami

                
                
3D Viewport Navigation:

                
    
                    
  • Rotate / Orbit: Click and drag with Left Mouse Button.
    • 
                    
  • Pan / Move: Right-click and drag (or Shift + Left Click drag).
    • 
                    
  • Zoom: Mouse Scroll Wheel.
    • 
                


                
Key Capabilities:

                
    
                    
  • 8 Analytical IK Configurations: Test Flip/No-flip, Elbow Up/Down, Shoulder Front/Back solutions.
    • 
                    
  • Live Matrix Breakdown: Inspect $[T_0^6]$ and $6\times6$ Jacobian $[J]$ with real-time singularity diagnostics.
    • 
                    
  • Interactive Lessons: Step-by-step guides on DOF, DH convention, and singularities.
    • 
                    
  • Multi-Language Code Generation: Export real robot controller code in Python, C++, Fanuc TP, and MATLAB.
